# Pipeline de producto — flujo v3

La forma en que un producto nace, se valida, se vende y se opera en esta empresa. No es una línea recta: es un loop con compuertas, y también sabe matar productos.

**Qué es:** el proceso por etapas (stage-gates) que convierte una idea en un producto operando, con una tesis multi-producto detrás. Fabian abre y cierra cada etapa. Cada handoff exige un artefacto explícito: **sin entregable no hay pase**.

**Las 10 paradas:**

| # | Etapa | En 1 línea |
|---|---|---|
| 0 | Sourcing | Analyst escanea el mercado en forma continua y mantiene un backlog de tesis priorizado. |
| 1 | Tesis | Fabian + Chief of Staff formulan la hipótesis con criterios de kill; red-team antes de gastar un ciclo. |
| 2 | Validación | Se busca evidencia: pricing validado con método, mapa de competencia y lista de lanzamiento. |
| 3 | Construcción | Spec escrita desde la evidencia → MVP + sales kit + legales base + checklist $0. |
| 4 | Dogfooding | Uso interno con criterios de salida explícitos: ¿lo usaríamos nosotros? |
| 5 | Lanzamiento | Se sale a vender con todo el equipo comercial alineado. |
| 6 | Comercial | Outbound compliant, negociación dentro de matriz pre-aprobada; venta = contrato + primer pago. |
| 7 | Onboarding & Activación | Setup del cliente y primera victoria; recién acá la venta está realmente cerrada. |
| 8 | Operación | Entrega, cobro (dunning), soporte con SLAs y P&L por producto. |
| 9 | Loops | Feedback → backlog de producto; testimonios → comercial. El producto nunca deja de iterar. |

**Las 3 compuertas de Fabian** (decide en 48h o la etapa se pausa sola):

1. **Compuerta 1** — al final de Validación: *se construye o se mata*.
2. **Compuerta 2** — al final de Dogfooding: el producto pasa el umbral para salir a vender.
3. **Compuerta 3** — al final de Lanzamiento/pre-Lanzamiento: *aprobación para salir a vender*.

**Reglas de flujo:** WIP máximo por etapa (sin excepciones), presupuesto semanal de atención de Fabian como WIP maestro, aislamiento de datos entre clientes (tenancy), y **validar antes de construir** — siempre.
